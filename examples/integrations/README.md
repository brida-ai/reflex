# Integration demos

These demos show how larger systems can compose Brida Reflex without moving credentials, authorization, deterministic execution, or protected side effects into a Reflex.

- [Browser extension semantic content filter](browser-extension-semantic-blocking/) — Manifest V3 demo: deterministic candidate selection + trusted loopback companion + `semantic-content-blocking` + DOM revalidation.

Integration demos are not official recipes and do not imply hosted availability. Each demo keeps Reflex recommendation-only and preserves application-owned authority.
