# Brida Reflex current contract

Revision: 2026-09-19

Use this only when the live Brida Reflex agent guide/manifest cannot be read.

## Product

Brida Reflex provides fast, typed semantic decisions before more expensive reasoning, agent work, or human review.

Current public positioning: Free Preview, no card, fair use, no automatic paid overage.

## Public surfaces

Current direction includes:

- Brida account / Organization identity;
- developer API key;
- REST Reflex API;
- MCP Reflex surface;
- public declarative recipe source;
- Brida SDK source, with package publication subject to its release gate.

Hosted recipe availability can lag the public recipe catalogue. Query the live API/MCP surface instead of assuming every recipe is executable.

## Official recipes

- agent-wakeup
- agent-router
- context-pruner
- tool-risk
- quality-gate

## Custom Reflex

Product direction is Organization-scoped, declarative Custom Reflex authoring with explicit activation and immutable active versions.

Do not assume authoring is live. Query current Brida surfaces first.

## Data and authority

Default current Preview route to non-sensitive data unless the active route explicitly permits more.

Reflex output is recommendation-only and never widens downstream authority.
