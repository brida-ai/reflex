# Brida Reflex

Open schema, recipes, fixtures, examples and agent-discovery surface for Brida Reflex.

This repository is currently staged privately while the first public schema and release-safety gates are completed.

Reflex is a programmable semantic decision capability: cheap, typed decisions before expensive reasoning.

This repository will contain portable public artifacts only. Hosted execution, tenant authority, metering, provider routing, private evals and internal product logic remain managed by Brida.

Community recipe contributions will be declarative and reviewed. A repository merge never automatically activates hosted production behavior.

See AGENTS.md before using an AI coding agent in this repository.
